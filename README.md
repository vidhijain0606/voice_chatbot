# Voice-Enabled Chatbot

A voice-enabled chatbot combining **browser-based Speech Recognition** (Web
Speech API) with a **Deep Learning intent-classification model** (Keras
feedforward neural network) trained on a custom intents dataset.

## How it works
1. Click **🎤 Speak** — your browser's Web Speech API transcribes your voice to text (client-side, no server round-trip needed for STT).
2. The recognized text is sent to a trained neural network that classifies it into an intent.
3. A response for that intent is returned and displayed, alongside the recognized transcript.
4. A manual text box is provided as a fallback for browsers without Web Speech support (e.g. Firefox).

## Run locally
```bash
pip install -r requirements.txt
python train.py   # trains the model, writes model/*.h5, *.pkl
python app.py      # launches the Gradio app at http://127.0.0.1:7860
```

## Project structure
- `data/intents.json` — training dataset (tags, patterns, responses)
- `chatbot_model.py` — preprocessing (tokenize/lemmatize/bag-of-words) + model architecture
- `train.py` — trains and saves the model
- `app.py` — Gradio web app (voice + text UI, inference, response display)
- `model/` — trained model artifacts (generated by train.py)
- `report.md` — lab report (dataset, architecture, methodology, results)

## Deployment
Hosted on Hugging Face Spaces (Gradio SDK). See `report.md` for the live link.
